# Problem Solving with TypeScript & OOP

## Assignment Overview

This assignment focuses on strengthening fundamental TypeScript concepts and Object-Oriented Programming (OOP) through practical problem-solving.

In this assignment, I have practiced and implemented various TypeScript concepts, including:

- Function parameters, optional parameters, and default values.
- Union types and type narrowing.
- Readonly tuples and array manipulation.
- Generics and reusable functions.
- Interfaces and object filtering.
- `keyof` and indexed access types.
- Classes, inheritance, and access modifiers.
- Asynchronous programming using Promises and `async/await`.

The main goal of this assignment is to improve my TypeScript problem-solving skills and understand how to write clean, reusable, and type-safe code.
